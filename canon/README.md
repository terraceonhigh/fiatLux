# Canon

This directory is a compact index of facts established by the manuscript.
It is not a story bible and does not contain model proposals.

- [`people.md`](people.md) records named people and explicit relationships.
- [`places.md`](places.md) records named and recurring places.
- [`chronology.md`](chronology.md) records only explicit ordering and intervals.

Every entry uses a provenance label and a manuscript line reference. Put
unsettled possibilities in `planning/` or `world/`, not here.
