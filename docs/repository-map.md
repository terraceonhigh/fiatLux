# Repository map

| Path | Purpose | Authority |
|---|---|---|
| `PROJECT.md` | Project rules for people and models | Governing contract |
| `manuscript/` | Terrace's prose and requested storyboards | Story authority |
| `canon/` | Settled names, relations, places, and chronology | Derived or ratified |
| `planning/` | Future chapters, arcs, candidates, and open questions | Mixed, labelled |
| `world/` | Material and institutional systems | Mixed, labelled |
| `research/` | Briefs and primary sources | Evidence |
| `publishing/` | AO3 manifest and operating instructions | External state |
| `tools/` | Reproducible checks, builds, and publishing commands | Implementation |
| `notes/` | Legacy model and session records | Historical evidence |

## Information flow

```text
manuscript -> canon -> planning dependencies
           -> world evidence

Terrace decisions -> planning or canon
primary sources -> research -> world constraints
model output -> labelled proposal
```

A model proposal cannot move directly into canon or finished manuscript prose.
