# World model

These files describe systems that constrain the story. They do not describe
themes or preserve session transcripts.

Use these provenance labels:

- `TEXT` for a claim that the manuscript states. Add a file and line.
- `TERRACE` for a decision that Terrace made.
- `SOURCE` for a claim that a cited source supports.
- `MODEL` for a proposal or inference from a model.
- `OPEN` when the repository does not settle the claim.

Each definition has one owning file. Other files link to that definition.

## Common structure

Use these sections in each system file:

1. Scope.
2. Established in the manuscript.
3. Terrace decisions.
4. Quantities and assumptions.
5. Dependencies.
6. Failure modes.
7. Substitutes and adaptations.
8. Open questions.
9. Sources.
