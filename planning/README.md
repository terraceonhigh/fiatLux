# Planning

This directory is the active home for future story work.

- `sequence.md` owns chapter order and draft state.
- `manuscript-ledger.md` records generated mechanical state.
- `chapters/` owns chapter-specific decisions, candidates, and questions.
- `arcs/` owns material that crosses chapter boundaries.
- `unplaced.md` owns ideas without a destination.
- `parked-prose.md` indexes unused prose written by Terrace.
- `worklist.md` owns manuscript edits that still need a decision.
- `idea-bank.md` preserves the mixed human/model idea record.
- `legacy/` and `sessions/` preserve historical material without granting it
  authority.
- `migration.md` records the completed disposition of the old notes tree.

Preserve model material when it can be useful. Label it. Do not promote it by
rewriting it in a more confident voice.
