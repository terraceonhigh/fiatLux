# Research

The files in `briefs/` are supporting evidence for worldbuilding. They are not
story authority. Check each cited source before promoting a claim into a world
file. Prefer primary sources and keep inference separate from sourced fact.

The `sources/` directory holds local copies of primary material when the
repository needs one. Do not store generated summaries there.

The `field/` directory holds Terrace's own reference photos from site visits,
resized for the repository, one folder per trip with a `README.md` review
list. They show what real places look like. They do not fix the book's map.
